<h2>📌 About the Project</h2>

<p>
This project is an interactive <b>Global SuperStore Sales Dashboard</b> developed
using <b>Microsoft Power BI</b>. The dashboard analyzes SuperStore sales data
across customers, products, regions, salespersons, revenue, margins, and item
quantities over the years <b>2021–2022</b>.
</p>

<p>
The dataset used for this project was obtained from <b>Kaggle</b>. The dashboard
was created to transform raw sales data into an interactive and visually
understandable report.
</p>

<p>
This is an <b>older project that I recently revisited and edited</b>. While
reworking the project, I improved the presentation, dashboard interaction, and
overall usability.
</p>

<h2>🎯 Project Objective</h2>

<p>
The main objective of this project is to analyze Global SuperStore sales data
and understand how products, customers, regions, salespersons, revenue,
margins, and item quantities contribute to overall business performance.
</p>

<h2>📊 Dashboard Overview</h2>

<p>
The dashboard provides an interactive overview of SuperStore performance through
multiple charts, filters, and summary indicators.
</p>

<h2>🎛️ Interactive Features</h2>

<ul>
  <li>
    <b>Customer Filter:</b> Filter the dashboard according to individual
    customers.
  </li>

  <li>
    <b>Product Filter:</b> Analyze specific products and their performance.
  </li>

  <li>
    <b>Region Filter:</b> View sales and margin information for selected regions.
  </li>

  <li>
    <b>Salesperson Filter:</b> Analyze data based on individual salespersons.
  </li>

  <li>
    <b>Dynamic Visuals:</b> Charts automatically respond to selected filters.
  </li>

  <li>
    <b>Column Sorting:</b> Data can be sorted in either
    <b>ascending or descending order</b> according to the user's requirement.
  </li>
</ul>
